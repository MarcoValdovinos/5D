## ⚙️ ¿Qué hace este código?

*   🛰️ **`sello.py`**: Captura tu GPS y hardware, genera una llave maestra, y firma documentos criptográficamente (HMAC).
*   🌙 **`index.html`**: Visualizador cimático interactivo. Calcula la posición exacta de la Luna en tiempo real usando el algoritmo de *Jean Meeus* e inyecta esa "verdad astronómica" en las ondas visuales.
*   🗄️ **`ledger.db`**: Base de datos SQLite local. Nadie más tiene acceso a tu historial.
